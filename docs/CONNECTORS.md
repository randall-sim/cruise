# Official course sources

Use [the browser task workflow](TASK_WORKFLOW.md) to read Canvas and course
websites through authenticated Chrome. Save `canvasUrl` and `websiteUrl` on each
course. Course workspace checkpoints and learning notes hold local progress.

Notion is no longer used for task discovery or status changes. Legacy connector
settings, optional fields and historical task records are retained for data
compatibility, not used as instructions to browse or sync. No account tokens or
connector setup are needed. Reopen Codex after updating to load current tool
descriptions; repository instructions supersede older cached descriptions.
